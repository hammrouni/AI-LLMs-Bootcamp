# 🚀 AI & LLMs Bootcamp (30 Days Challenge)

<div dir="rtl">

مرحبا بيكم في الـ Bootcamp هذا !

</div> 
<div dir="rtl">

هذا برنامج على 30 يوم (بمعدل 2-3 سوايع في النهار) موجه الـ Developers والـ Software Engineers لي يحبو يفهمو الـ AI والـ Large Language Models (LLMs) ويخدموا بيهم في مشاريعهم.

</div>

<div dir="rtl">

الـ Approche متاعنا هي **"Top-Down"**: باش نبداو بالـ Application Level والـ APIs، ونهبطو بشوية بشوية للـ Models، الـ Training، والـ Architecture من داخل.

</div>

---

## <div dir="rtl">🎯 الأهداف متاع الـ Bootcamp</div>
<div dir="rtl">

- فهم كيفية دمج الـ LLMs في الـ Architectures الحالية.
- إتقان الـ Prompt Engineering والـ RAG (Retrieval-Augmented Generation).
- بناء AI Agents قادرة على اتخاذ القرارات (Reasoning & Action).
-  بش تخدم الـ models en local
- فهم أساسيات الـ Fine-Tuning والـ Reinforcement Learning (RLHF).

</div>

---

## 📅 Planning (30-Day Curriculum)

### 🛠️ Week 1: Application Layer & Ecosystem
* **Day 01-02:** Python Basics & AI APIs
* **Day 03:** Advanced Prompt Engineering (Chain of Thought, Few-Shot, JSON Parsing)
* **Day 04-05:** Essential Frameworks: LangChain & LlamaIndex
* **Day 06-07:** Mini-Project: Building a Smart Chatbot with Memory

### 🧠 Week 2: Private Data & Local Models
* **Day 08-09:** Embeddings & Vector Databases
* **Day 10-11:** Building a Complete RAG System
* **Day 12-13:** Local Models with Ollama
* **Day 14:** Evaluating Models & RAG Systems

### 🤖 Week 3: Automation & AI Agents
* **Day 15-16:** Function Calling & Tool Use
* **Day 17-18:** Building AI Agents
* **Day 19-20:** Workflows & Model Context Protocol (MCP)
* **Day 21:** Advanced Agent Review & Implementation

### 🔬 Week 4: Deep Dive & Final Project
* **Day 22-23:** Transformer Architecture & Hugging Face
* **Day 24-25:** Parameter-Efficient Fine-Tuning (PEFT) & LoRA
* **Day 26:** Reinforcement Learning from Human Feedback (RLHF)
* **Day 27-30:** 🏆 Final Project: Complete Architecture (Frontend, Backend, RAG, Local & API Models, Agents)
